# Corpus attribution

"Cosine similarity"), fetched 2026-10-18 via the Wikipedia REST API. Text is available under CC BY-SA 4.0
(https://creativecommons.org/licenses/by-sa/4.0/); authorship is per the articles' page histories.
The other three corpus documents were written for this project (see scripts/generate_corpus.py).
